# pi-team promotional demo

This 40-second product film introduces pi-team for PI Agent developers. It uses the package's existing visual identity and shows the real workflow: session setup, concurrent local coordination, persistent requests, and correlated results.

[Watch or download the MP4](pi-team-demo.mp4)

## Media details

- 1920 × 1080 at 30 fps
- H.264 video with AAC stereo audio
- English on-screen copy
- No voice-over
- Original instrumental soundtrack with no external samples

The MP4 is stored outside the npm package contents so installing the extension does not download promotional media.
