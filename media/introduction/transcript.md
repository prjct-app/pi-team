# pi-team — narrated introduction

English synthetic narration. Illustrative workflow, not a live recording.

Meet Pi Team. Connect independent Pi Agent sessions, and keep work moving between them.

Create a team once. Then join each terminal with its own alias.

Send a task to a teammate. It waits in the queue until that session is ready.

When the work finishes, a result returns to the requester, linked to the original task.

Each session keeps its own model, workspace, and conversation. Pause new work whenever you need to.

Start with Pi Team. Independent. Connected.
